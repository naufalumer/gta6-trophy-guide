Leonida Legend is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy carries its official name, description and grade, a guide in our own words with numbered steps and a cited source, an honest time estimate and difficulty, and a flag where it can be missed — the one confirmed missable (Positive Mental Attitude, Chapter 1 balcony meditation) is called out up front. The tracker saves progress in the browser, filters by grade, kind and difficulty, sorts quickest/longest, hides spoilers for hidden trophies, and exports, imports and resets progress. A six-stage Roadmap to Platinum orders the whole run, with remaining time per stage. The whole app is static files under app/ and works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
