Leonida Legend is a complete offline guide and progress tracker for all 55 GTA VI trophies: original guides with numbered steps, honest time estimates and difficulty ratings, a 6-stage roadmap to the platinum, and a checklist that saves in your browser. One trophy is confirmed missable (Positive Mental Attitude, with a manual Chapter 1 save warning), and four counts are honestly flagged COUNT UNCONFIRMED. Every guide cites its sources; the official trophy names, descriptions and grades are shown exactly as PlayStation publishes them.

## Run it

node serve.ts
