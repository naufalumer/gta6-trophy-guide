Leonida Legend is a fan-made tracker and guide covering every one of the 55 Grand Theft Auto VI trophies on PlayStation 5. Each entry pairs the official name, description and grade — shown exactly as PlayStation publishes them — with an original guide written for this entry and the source it draws on. Progress is saved in your browser, exportable and importable; search, grade and kind filters, a spoiler setting for story trophies, and a six-stage roadmap walk you to the platinum. The single trophy that can actually be missed — Positive Mental Attitude, Lucia's Chapter 1 balcony meditation — is flagged first, and the four counts launch-week lists could not confirm are marked unconfirmed instead of stated as fact. It is plain static files under `app/`, no build step, no network at run time, so it works fully offline. Every trophy also carries a rough time estimate and a 1–5 difficulty rating, with quickest-first sorting and a running count of the trophy work still left — the estimates are labelled as estimates, and the full run stays ~200 hours per launch-week guides.

## Try it locally

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
