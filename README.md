Leonida Legend is an offline trophy guide and tracker for Grand Theft Auto VI on PlayStation 5: all 55 trophies with their official names, descriptions and grades, an original guide and numbered steps for each one, honest time estimates and difficulty ratings, a six-stage roadmap to the platinum, and a checklist that saves progress in the browser. The one confirmed missable trophy is flagged with a glowing badge, and the four counts nobody has verified yet are labelled COUNT UNCONFIRMED rather than guessed.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080 — no network needed, everything is local files.
