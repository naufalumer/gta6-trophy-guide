Leonida Legend is an offline guide and tracker for all 55 GTA VI trophies: every trophy with its official name, description and grade, a guide in our own words with its source named, a six-stage roadmap to the platinum, a checklist that saves progress in the browser, filters by grade and kind, a spoiler setting, per-trophy time estimates and difficulty, and export/import of progress. The one confirmed missable trophy is flagged loud and early. Works with the network off.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
